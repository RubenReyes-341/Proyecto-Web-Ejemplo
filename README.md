# Proyecto-Web-Ejemplo
Proyecto de curso de aprendizaje de Git y Github, pagina web creada personalmente para un proyecto de mi servivcio social.

## Cómo clonar y ejecutar el proyecto en un entorno local

Para clonar un repositorio en una máquina local, se debe ejecutar el comando: git clone link-de-repositorio

## Descripción de las ramas del proyecto

- **main**: Rama principal que contiene la versión final y estable del sitio web.

- **feature-mejora-estilo**: Rama utilizada para mejorar el estilo y la presentación
  visual del sitio web. En esta rama se realizaron cambios en los archivos CSS y HTML,
  los cuales, despues se integraron a la rama del "main".
